 # E-Commerce Database Management System

## 📌 Project Overview

This project is a MySQL-based **E-Commerce Database Management System** designed to manage customers, products, orders, order details, categories, and payments.

The project demonstrates practical SQL concepts used for storing, managing, and analyzing e-commerce data.

## 🛠️ Technologies Used

* MySQL
* SQL
* MySQL Workbench

## 📂 Project Files

* `database.sql` — Database, tables, and sample data
* `queries.sql` — SQL queries and business analysis
* `README.md` — Project documentation

## 🗃️ Database Tables

The database contains the following tables:

1. **customers** — Stores customer information.
2. **products** — Stores product details, prices, stock, and categories.
3. **categories** — Stores product categories.
4. **orders** — Stores customer orders.
5. **order_details** — Stores products included in each order.
6. **payments** — Stores payment information.

## 🚀 How to Run

1. Open MySQL Workbench.
2. Open `database.sql`.
3. Execute the complete file to create the database, tables, and sample data.
4. Open `queries.sql`.
5. Execute the queries to analyze the e-commerce database.
